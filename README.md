## 🛠️ 工程全局物理资源映射 (Hardware & Memory Blueprint)

### 1. 片内 Flash 分区 (STM32F103C8T6 - 64KB Flash)
* `0x08000000 - 0x08001FFF` (8KB): **Bootloader 分区**（引导、元数据解析、旧固件备份、新固件搬运、回滚）
* `0x08002000 - 0x0800FFFF` (56KB): **APP 固件运行分区**（FreeRTOS 调度器 + 业务驱动，中断向量表偏移 `0x2000`）

### 2. 片外 SPI Flash 拓扑 (W25Q64 - 8MB / 4KB 扇区对齐)
* `0x000000 - 0x000FFF` (4KB): **BootMeta 升级元数据扇区**（Magic、升级状态、固件大小、CRC32、重试计数）
* `0x001000 - 0x01FFFF` (124KB): **NewFirmware 新固件暂存区**（UART IAP 接收下载区）
* `0x020000 - 0x03FFFF` (128KB): **BackupFirmware 上一稳定版固件备份区**（供升级异常时自动回滚）
* `0x040000+`: 用户数据与日志区
