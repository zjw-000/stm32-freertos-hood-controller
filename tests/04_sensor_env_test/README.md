一、 使用 DHT11 需要哪些 STM32 外设配置？
[时钟]：使能 GPIOC 端口时钟（APB2 总线）。
[GPIO]：单总线双向动态切换，主机发送起始信号时配置 PC14 为推挽输出（GPIO_Mode_Out_PP），接收应答与数据时切换为浮空输入（GPIO_Mode_IN_FLOATING）。
[外设]：依赖微秒级精准延时（基于 SysTick 系统定时器或普通定时器延时），无需硬件通信外设控制器。
[中断/DMA]：未配置中断与 DMA，通信采用软件微秒轮询，为防止时序被高优先级任务打断，关键时序窗口通常需配合临界区保护。
[硬件电路]：单总线（DATA）引脚接 PC14，外部需并联一颗 4.7kΩ~10kΩ 上拉电阻至 3.3V/5V，总线空闲时自动维持高电平。
[调试验证]：逻辑分析仪或示波器抓取 PC14 时序波形，校验 18ms 起始拉低、80us 响应脉冲以及 40 位数据电平宽度，串口打印温度、湿度与校验和。

二、 高阶口述复现流程
1. 记忆抓手（锚点）
“DHT11 单总线通信 = 毫秒级主机敲门 + 80us 从机双向握手 + 高电平脉宽区分 0/1 + 40 位校验和闭环”。

2. 口述复现链路
【1】主机起始敲门：单片机将 PC14 配置为推挽输出，主动拉低总线至少 18ms（打破空闲上拉），随后拉高 30us 并迅速切为浮空输入，交出总线控制权。  
【2】从机响应握手：DHT11 检测到起始信号后接管总线，先拉低 80us 作为响应信号，再拉高 80us 通知单片机“准备发送数据”。  
【3】40 位逐位传输：DHT11 连续吐出 5 字节（40 bit）数据。每一位都以 50us 低电平开始，随后拉高电平：高电平持续 26~28us 表示逻辑 0，持续 70us 表示逻辑 1。  
【4】延时窗口判决：单片机检测到 50us 低电平结束、电平变高后，精准延时 30us 进行采样——若此时引脚仍为高电平，则判定为 1；若引脚已变为低电平，则判定为 0。随后等待该位高电平彻底结束，通过左移拼接进数据字节。  
【5】校验和闭环判定：接收满 5 个字节后，主程序执行前 4 字节累加（湿度高位 + 湿度低位 + 温度高位 + 温度低位），判断低 8 位是否等于第 5 字节的校验和（CheckSum），校验通过才采纳温湿度数据。

3. 口述闭环金句
“DHT11 的驱动核心在于以时间脉宽调制（PWM）换取硬件引脚资源：单总线半双工通信极度依赖微秒级时序容限，软件上通过‘30us 采样窗口法’可以极其优雅地解耦 0 和 1 的宽度判定，最后配合校验和杜绝偶发误码。”

一、使用 MQ-2 需要哪些 STM32 外设配置？

[时钟]：使能 GPIOA 端口时钟与 ADC1 外设时钟（APB2 总线），配置 ADC 预分频因子为 6 分频（72MHz/6 = 12MHz，严控在 14MHz 极限以内）。
[GPIO]：配置 PA4 引脚模式为模拟输入（GPIO_Mode_AIN），关闭数字施密特触发通道。
[外设]：配置 ADC1 为独立模式、单通道、单次转换、右对齐、软件触发；执行复位校准与硬件校准消除制造零点漂移。
[中断/DMA]：测试工程采用单通道软件轮询 EOC（转换完成）标志位，未使能中断与 DMA。
[硬件电路]：传感器 AO（模拟输出）引脚连接单片机 PA4，VCC 供电 5V 驱动内部加热丝，板载分压电阻输出 0~3.3V 安全量程。
[调试验证]：示波器量取 PA4 模拟直流电压变化，或通过串口输出原始 ADC 采样读数（0~4095）。

二、 📊 流程演示（以一次真实烟雾报警调用为例）
示范 2：MQ-2 气体传感器（ADC 采集与浓度反算）
1. 记忆抓手（锚点）
“MQ-2 采集 = 气敏阻值变电压 + ADC 硬件量化 + 均值滤波降噪 + 对数曲线换算 PPM”。

2. 口述复现链路
【1】物理阻抗转换：MQ-2 遇到烟雾或可燃气体时内阻剧烈下降，与板载负载电阻分压后，在 PA4 引脚输出一个抬高的模拟直流电压（0~3.3V）。  
【2】单次 ADC 量化：程序配置通道 4 采样时间为 239.5 周期，触发软件转换启动后轮询 EOC 标志位，等待约 17us 硬件量化完成，从数据寄存器读出 12 位原始 ADC 值（0~4095）。  
【3】循环滤波平滑：连续采集 10 次做滑动均值滤波，滤除环境工频干扰和电源波动毛刺。  
【4】物理量与浓度反算：先将 ADC 值线性换算为引脚实际电压V，再根据分压电路反推传感器当前内阻RS，最后代入对数标定曲线函数计算出实际气体浓度（PPM）。  
【5】阈值判决：将算出的 PPM 与预设报警阈值（如 100 PPM）比较，超标则置位报警标志，联动风机强排。

3. 口述闭环金句
“MQ-2 的采集链路非常标准：硬件层利用阻值分压转为电压，采集层用 ADC 硬件完成量化并配合均值滤波抑制噪点，算法层通过传感器对数特性方程还原真实 PPM 浓度完成闭环判定。”
