一、 使用 1.8 寸 TFT-LCD 需要哪些 STM32 外设配置？
[时钟]：使能 GPIOA、GPIOB（APB2 总线）以及 SPI1 硬件外设时钟（APB2 总线）。
[GPIO]：配置 PA5（SPI1_SCK）与 PA7（SPI1_MOSI）为复用推挽输出（GPIO_Mode_AF_PP）；配置 PB6（背光 LED）、PB7（数据/命令选择 RS）、PB8（复位 RST）、PB9（片选 CS）为通用推挽输出（GPIO_Mode_Out_PP）。
[外设]：配置 SPI1 为主机单向发送模式、8 位数据帧、时钟空闲为高且偶数沿采样（CPOL=1, CPHA=1，Mode 3）、软件 NSS、波特率预分频设为 2 分频（最高 36MHz 满速发送）。
[中断/DMA]：测试工程采用 SPI 查询发送标志位（SPI_I2S_FLAG_TXE），未使能中断与 DMA（项目高阶版可扩展 SPI-DMA 刷屏提高吞吐量）。
[硬件电路]：驱动芯片为 ST7735，分辨率 128×160，色彩模式 RGB565（每个像素 16 位），单片机通过 4 线 SPI 控制总线通信，PB6 控制背光导通或接入 PWM 调光。
[调试验证]：逻辑分析仪量取 SCK/MOSI/RS 信号确认指令与像素流时序，上电后通过全屏纯色填充（红/绿/蓝/黑/白）验证屏幕坏点、方向及色彩映射是否正常。

二、 高阶口述复现流程（极简重构版）
1. 记忆抓手（锚点）
“LCD 刷屏 = RS 引脚分流 + 圈定显示窗口 + SPI 连续灌入颜色”。

2. 口述复现链路
【1】硬件复位与唤醒：单片机拉低 RST 引脚产生复位脉冲，接着通过 SPI 发送唤醒指令与伽马参数，屏幕上电自检并开启内部背光显存。  
【2】RS 引脚切换模式：驱动核心依靠 RS（A0）引脚进行指挥：RS 为低电平时，发的是控制指令（如划定绘图范围）；RS 为高电平时，发的是纯像素数据（RGB565 颜色值）。  
【3】圈定绘制窗口：每次要画图、写字或清屏前，先发指令告诉屏幕控制器本次绘制的 X 坐标起止范围 和 Y 坐标起止范围，在屏幕显存上框出一个虚拟的矩形作业区。  
【4】开启显存连写：单片机下发“准备写显存”命令后，立刻将 RS 拉高切入数据模式。  
【5】高速推流填色：单片机通过硬件 SPI 连续灌入 16 位的 RGB565 颜色点。每送入一个点，屏幕控制器硬件内部的显存指针就自动向右自增、自动换行，直到把整个矩形框填满。

3. 口述闭环金句
“LCD 驱动的核心在于‘先圈框、后灌色’：利用 RS 引脚在‘指令’和‘数据’之间解耦，MCU 只要先划定目标矩形窗口，后续就能借助硬件 SPI 全速无脑推流填色，显存光标由硬件自动自增，极大降低了单片机的绘图开销。”
