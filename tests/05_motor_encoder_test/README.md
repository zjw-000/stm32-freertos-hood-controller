一、 使用该编码器需要哪些 STM32 外设配置？
[时钟]：使能 GPIOA 端口时钟（APB2 总线）与 TIM2 定时器外设时钟（APB1 总线）。
[GPIO]：配置 PA0（TIM2_CH1）与 PA1（TIM2_CH2）引脚模式为下拉输入（GPIO_Mode_IPD）。
[外设]：配置 TIM2 时基单元（ARR=65535, PSC=0），通道 1 与通道 2 开启输入滤波（Filter=10），并调用 TIM_EncoderInterfaceConfig 开启 TIM_EncoderMode_TI12 硬件正交编码器 4 倍频计数模式。
[中断/DMA]：使能 TIM2 更新中断（TIM_IT_Update）并配置 NVIC 优先级，在中断服务函数中维护 overflow 溢出圈数变量，防止 16 位计数器回绕溢出丢脉冲。
[硬件电路]：直流电机尾部双通道霍尔编码器的 A 相与 B 相分别接单片机 PA0 和 PA1，编码器电源接 5V/3.3V 供电。
[调试验证]：手动盘动电机轴或用示波器抓取 PA0/PA1 两路正交相位波形，串口打印读取 TIM2->CNT 计数值，校验计数的增减与转动方向是否吻合。
二、 📊 流程演示（以一次真实电机加速与脉冲回读为例）
编码器（TIM2 正交解码与测速）
1. 记忆抓手（锚点）
“编码器硬件测速 = 双相正交方波 + 定时器硬件 4 倍频计数 + 溢出软扩展 + 1秒时间窗读数”。

2. 口述复现链路
【1】电机运转出波：电机旋转带动尾部霍尔编码器，在 PA0、PA1 上输出两路相位差 90° 的正交方波，转速越快，脉冲频率越高。  
【2】硬件滤波与 4 倍频：方波进入 TIM2，内部数字滤波器先滤除电刷换向毛刺；硬件解码器对 A/B 相的全部上升沿和下降沿进行计数（4 倍频），正转自动 CNT++，反转自动 CNT--，全程不占用 CPU。  
【3】溢出中断防回绕：TIM2 为 16 位计数器（最大 65535），转速过高计满时触发更新中断，在 ISR 中累加 overflow 圈数，避免高转速下丢脉冲。  
【4】定时回读与算速：主程序以 1 秒为采样周期调用 get_encoder_value()，通过公式 总脉冲 = overflow * 65536 + CNT 算出 1 秒内增量，进而换算为真实转速（RPM）。

3. 口述闭环金句
“整个测速方案的核心在于动静解耦：A/B 相的高频脉冲计数完全托管给 TIM2 硬件外设，CPU 只需要开一个 1 秒的软定时器直接读结果算转速，做到了极低的系统开销。”
